# oliveira · 学习打卡

基于《学习规划全记录.md》+ VR261 个人课表 + 校历（2026–2027 第一学期）做成的单文件学习打卡应用：**双击 `index.html` 用浏览器打开即用**（推荐 Chrome / Edge），无需安装、无需联网。

## 功能

- **🗓 课表页（新增）**：12 节次 × 7 天完整课表网格，自动高亮「本周上课的课程 / 今天列 / 当前节次」，课程按周次区间显示（如「第 4–13 周」），结课/未开课自动变灰
- **每天自动更新**：按系统日期自动生成当日任务——固定仪式（百词斩 / 新概念 2 课次自动递进 / 走圈）+ 与真实课表对齐的当日板块（黑马 C++ 周章节自动推进）+ 艾宾浩斯单词到期组（A–H 组按 +1/+3/+6/+14/+29 天自动计算）+ 特殊事件（运动会轻学习包、期中冲刺周、期中考试）
- **课程周次自适应**：思修（4–13 周）/心理（4–11 周）结课后对应时段自动回归自习；形策 13 周开课后周三下午自动切换；期中后周六日自动进入期末积累模式
- **自己 return 任务**：勾选即打卡（记录完成时间），再点一次撤销；每条任务可写备注；可随时添加 / 删除自定义任务；每天有「今日小结」复盘
- **👤 账户登录（GitHub）**：登录后数据自动同步到你的 GitHub 私有 Gist，任何设备登录同一账号即自动合并迁移（无服务器方案）；不登录也可用「导出 / 导入 JSON」手动迁移
- **📱 手机版**：完整移动端适配（横向滑动课表 / 周卡、大点击区、粘性节次列、深色模式），可「添加到主屏幕」像 App 一样使用
- **可视化**：今日完成率环形图、近 7 天完成率柱状图、近 7 天各科投入条形图、本周 7 天卡片 + 38h 底盘 + 班长事务 3h 红线、连续打卡、累计投入、百词斩词量、227 词艾宾浩斯进度、顶部倒计时胶囊
- **简约风格**：浅色 / 深色主题，纯 CSS + SVG 手绘图表，无任何外部依赖

## 数据

- 本地数据存在浏览器 localStorage（键 `jiangpan-study-v1`）
- **云端同步**：「账户」页用 GitHub classic token（只需 `gist` 权限）登录 → 数据存到你的私有 Gist（描述 `oliveira-study-data-v1`），每次打卡后自动同步；换设备登录同一账号自动合并
- 手动备份：左下角「导出数据」JSON，「计划 → 导入数据」恢复

## 可调整

`index.html` 内 `<script>` 开头的常量区：

- `COURSES`：课程、老师、教室、星期、节次、起止周（课表页和每日任务都从这里生成）
- `DAY`：每日自习板块（`{course:'xx'}` 引用课程，`alt` 是课程不上的替代任务，`onlyIf` 是课程上课时才出现的任务）
- `GROUPS` / `EVENTS`：单词组与特殊事件日期
- `PERIODS`：节次时间表

改完保存刷新即可。
